# Remy Mr Nocomment — Cinema Hub

A Vue and Vite movie-discovery app with an Express API. AI chat uses the connected Vercel AI Gateway in v0 and Vercel runtimes; no Gemini API key is required there.

## Run Locally

**Prerequisites:**  Node.js


1. Install dependencies:
   `npm install`
2. AI chat uses Vercel AI Gateway automatically in v0 and Vercel runtimes. The current gateway setup does not require a Gemini API key.
3. Run the app:
   `npm run dev`
